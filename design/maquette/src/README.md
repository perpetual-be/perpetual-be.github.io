# design/maquette/src — outils de la maquette (lot 2)

Exécuter depuis la racine du dépôt.

- `build.mjs` → génère les pages de `design/maquette/` (`index.html`, puis la fiche et la vue Projets) à partir de `data/*.json`, `content/*.md`, `public/favicon.svg`, `public/partners/` (logos en couleur, hauteurs lues sur l'encre) et `carte/belgique.svg`. La photo du premier écran (Community 05) et son point focal sont dans `photoCandidates`. Aucune dépendance hors Node : `node design/maquette/src/build.mjs`.
- `carte/belgique.svg` → la carte de la section Réalisations (contour, 17 points, 17 étiquettes placées à la main ; les quatre adresses bruxelloises sont un seul point plus gros, r 6,5, sous l'étiquette « Bruxelles » ; `belgique.json` porte les coordonnées et le groupe). `build.mjs` l'inline en regroupant chaque étiquette avec son point (`<g class="carte__lieu">`) : le survol d'un point colore l'étiquette en CSS seul (les villes sont figées sur « toutes », visibles sans survol). `data-rang="1"` sur une étiquette du SVG la garde visible sur mobile (les autres s'y effacent, faute de place) ; pour changer la sélection, ajouter ou retirer l'attribut dans le SVG, puis rebâtir.
- `check.mjs` → vérifications automatiques (premier écran à 1440 × 900 et 1366 × 703, débordement horizontal, effet de chaque bascule, paramètres des bascules retirées sans effet, valeurs figées et alignement, titres `.h2--sans` / `.h2--serif`, en-tête, carte des réalisations, logos partenaires, photo 2800 px, mode présentation, page sans JavaScript, polices, contrastes).
- `export.mjs` → captures PNG, panneau masqué ; par défaut les pages présentes en 1440 pleine page et 390, échelle 2, dans `design/maquette/export/`. Options : `--etat "cadrage=haut&serif=source-serif"`, `--pages`, `--formats 1440,1366,390`, `--out`, `--echelle`, `--ecran`.

`check.mjs` et `export.mjs` demandent Playwright : `npm install -D playwright` à la racine (puis `npx playwright install chromium`), ou une installation globale avec `NODE_PATH=$(npm root -g) node design/maquette/src/export.mjs`.

Les pages s'ouvrent directement dans le navigateur (`file://`). L'état des bascules est dans la query de l'URL (`index.html?cadrage=haut&serif=source-serif`), le hash reste aux ancres ; `?panneau=off` masque le panneau, Échap le rappelle. Un paramètre d'une bascule retirée, resté dans une URL, n'a plus d'effet. `maquette.css` porte les jetons et les composants, puis une région « bascules » en fin de fichier ; `maquette.js` ne contient que le panneau, la lecture et l'écriture de l'état, et l'aperçu de la liste des projets. `fonts/` ne contient que les polices encore utilisées (Newsreader, Source Serif 4, Instrument Sans, Jost) ; les autres restent dans `design/directions/fonts/`.
